# teumta admin (archived)

2026-09-08 결정에 따라 이 관리자 웹은 운영·배포·신규 개발 대상에서 제외한다.

- 기존 장소·태그·저장형 코스·KTO 매칭 구현은 향후 참고 가능성을 위해 보존한다.
- 서버의 `/api/admin/*` 구현도 당장은 보존한다.
- CI와 배포 대상에는 포함하지 않는다.
- 다시 사용할 때는 `VITE_API_BASE_URL`, `CORS_ALLOWED_ORIGINS`, 인증·의존성 보안 상태를 먼저 재검증한다.

모바일 앱은 관리자 웹이나 저장형 Route에 의존하지 않고 실시간 `/api/courses` 경로를 사용한다.
